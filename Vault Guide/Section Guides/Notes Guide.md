## Use general notes for flexible capture

Use Notes for working ideas, research, longer troubleshooting observations, or miscellaneous information that does not yet belong in a project, meeting, or reusable KB article. Keep quick temporary text in the daily Scratch Pad instead.

Click **New Note** in the daily note or Notes Dashboard. Enter a title and optional project/application selections. The note is created as Notes/YYYY-MM-DD - Title.md with Notes and Related Links sections. Repeated filenames receive a numbered suffix.

Daily-note creation adds a Created Today reference; dashboard creation does not.

## Link and revisit

The projects and applications properties hold actual note links. Select relationships during creation or add them later through Properties. The Notes Dashboard shows these relationships alongside each note and its last update.

Project and Application templates include Related Notes sections that display linked general notes. Existing project/application notes need these sections copied in once.

Tasks entered in Notes are not included in the daily open-action queries. Put an actionable task in the daily note, meeting, or project, and link back to the general note for detail.

## Promote lasting knowledge

When research becomes a confirmed procedure, create a KB article and link the original note to it. If it becomes an initiative, create a project. Avoid creating duplicate active tasks in both notes.

Screenshots pasted here go to Notes/Attachments under the recommended attachment setting.
