## Create a project

Click **New Project**, enter a name, and optionally select an existing application. Creating Print Server Migration makes Projects/Print Server Migration/Print Server Migration.md. Existing named folders are protected. Use the existing project rather than creating another copy.

Created from a daily note, the project also receives a Created Today reference there. Dashboard creation opens the project without adding a daily reference.

## Keep the project actionable

Record Objective, Current Status, Next Actions, Progress / Notes, and Related Links. The Current Status section is narrative; the status Property controls dashboard filtering.

| status Property | Use when |
| --- | --- |
| Active | Work is in progress |
| Waiting | Progress depends on a response, approval, or dependency |
| Completed | The initiative is finished |
| Cancelled | The initiative has been stopped |

New projects start as Active. Use the Project Status dropdown to save these values. Dashboard filtering also tolerates capitalization differences. The dashboard highlights Active and Waiting; older projects with no status are also included. All Projects lists notes with type: project. Supporting Markdown files are not listed as projects.

Unchecked Next Actions appear in the daily open-action view. Changing project status does not complete or cancel those tasks.

## Meetings, applications, and KB

Set applications to the relevant application overview notes and kb_articles to specific procedures. Create meetings with this project's link in their projects property. Related Meetings then finds them automatically.

Directly Related KB Articles includes explicit articles and articles linked to the project. KB Articles for the Same Application provides broader context without mixing those results into direct references.

## Documents

Keep PDFs, downloads, and supporting files inside the project folder. Project Documents lists all other files in the folder and subfolders, including other Markdown notes. Paste screenshots into the project note to use Projects/Project Name/Attachments.

For a rename, use Obsidian and verify both the note and containing folder: renaming the note does not rename its folder automatically. Preserve links rather than deleting and recreating the project.

## Close out actions

The dashboard lists open actions on Completed or Cancelled projects separately. Resolve or cancel each action explicitly. General notes linked through projects appear under Related Notes.
