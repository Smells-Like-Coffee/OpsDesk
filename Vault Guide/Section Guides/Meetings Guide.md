# Meetings

[[ReadMe|Home]] · [[Meetings/Meetings Dashboard|Open Meetings Dashboard]]

Click **New Meeting** from the daily note or Meetings Dashboard. Enter a descriptive title, select an optional project/application, and click Create. The file is Meetings/YYYY-MM-DD - Title.md. The recorded date is the meeting date selected in the creation prompt. Renaming the file or editing date does not automatically update the other.

## Capture useful outcomes

Fill in Participants, Notes, Decisions, and Action Items. Use a checkbox for each real next action and put the owner or timing in its text when useful. Unchecked meeting actions appear in the daily note's Open Meeting and Project Actions section.

## Connect the meeting

Use projects to link the project note, applications to link an application overview, and kb_articles for specific procedures discussed. If you select a project and leave application blank during creation, its application links are inherited once. Explicit application selection overrides that inheritance.

Directly Related KB Articles shows explicit article references and articles associated with the same project. KB Articles for the Same Application shows additional application-related articles. The project note's Related Meetings section finds meetings whose projects property links to it.

The dashboard lists typed meeting notes in Meetings, excluding itself. It does not automatically import calendar meetings or restrict the view to upcoming dates.

Creation from a daily note records a Created Today link. Screenshots pasted into meetings go to Meetings/Attachments under the recommended setting.

## Meeting date

The creation prompt includes Meeting date, defaulting to today. Choose the actual meeting date; the filename and date property use that date. Created Today records when you created the entry, even if the meeting is on another day.

## Dashboard Base

The main listing is now an editable Base table. Use its view selector to change views and edit Properties directly. Creation buttons and relationship behavior remain unchanged. See [[Vault Guide/Section Guides/Bases Guide|Bases Guide]].
